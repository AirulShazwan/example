# Visit Perlis — tourism website

A complete responsive **front-end website** built in HTML, CSS and JavaScript with no mandatory libraries or backend.

## Open it

1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. An internet connection is recommended to load photographs from Wikimedia Commons and the optional Google Fonts. Without it, the website, search and itinerary functions still work; images show their fallback backgrounds.

To publish, upload the **entire folder contents** to a static web host (GitHub Pages, Netlify, Cloudflare Pages, etc.) with `index.html` in the root.

## Features

- Custom premium navy/dusty-blue/cream brand palette: `#0D1321`, `#748CAB`, `#F0EBD8`, `#1D2D44`.
- Responsive desktop, tablet and mobile layouts.
- Destination search, category filtering, detail pop-ups, and browser-saved favourites.
- Functional rule-based personalised itinerary generator: 1–5 days, date, travel group, interests and pace.
- Editable day-by-day itinerary: move stops up/down, delete, add, reset, print, download `.txt`, copy/share.
- Itineraries and language choice saved to this browser using `localStorage` where supported.
- Seasonal experience cards and month-sensitive tips.
- English / Bahasa Melayu switch.
- Links to Google Maps searches for destinations and source references.
- Image attribution/licensing credits in the website footer.

## Scope and important notices

This is an editorial, static front-end website, **not** a live booking service. No accounts, maps API, accommodation search, database, weather service or itinerary route-distance calculations are provided. The trip generator uses a local list of attractions and rule-based scoring. Times shown in itineraries are approximate *suggested visit slots*, not verified opening times, actual travel times, or reservation availability. For production use, confirm each attraction's accessibility, hours and current operations with local providers.

Photographs are linked from Wikimedia Commons and require an internet connection. Their creators, image pages and licence details are linked under **Image credits & licensing** in the footer. Reuse must comply with each individual photo licence and attribution obligations; photographs may be cropped by CSS. Several destinations without verified pictures use custom geometric fallback art rather than falsely presenting a photo of another location.
